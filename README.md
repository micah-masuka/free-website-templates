# free-website-templates

Free, responsive HTML/CSS website templates — each built around a specific format (memo, menu, syllabus, property sheet, and so on), not a shared component library.

**12 templates** in `templates/`. Open any `index.html` in a browser to preview.

Sample content uses Zimbabwean places and +263 contact details where relevant. Replace names, copy, and links with your own.

See `template-roadmap.txt` for what is included and what is planned.
