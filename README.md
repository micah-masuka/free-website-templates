# Free website templates

12 HTML and CSS templates. MIT licence. Use them, edit them, give them to a client.

**Share this link:** [github.com/micah-masuka/free-website-templates](https://github.com/micah-masuka/free-website-templates)

Preview: [micah-masuka.github.io/free-website-templates](https://micah-masuka.github.io/free-website-templates/)

## How to give one out

1. Send the GitHub link, or **Code → Download ZIP**
2. Open any folder in `templates/`
3. Double-click `index.html`, or edit the copy in a text editor

Each template is its own small site. Sample names and +263 numbers are placeholders. Swap them for real content.
