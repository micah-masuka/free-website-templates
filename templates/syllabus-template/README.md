# Syllabus (Course)

## What this is
Eight-week evening cohort syllabus — meta table, policies, week-by-week topics and deliverables, materials list.

## Files
- `index.html` — full syllabus
- `syllabus.css` — document layout, week rail
- `print.css` — handout printing
- `design-notes.txt` — university syllabus format

## How to edit
- Course title and code: `.mast`
- Schedule meta: `.meta-table`
- Weekly content: each `.week` section
- Policies and materials: `.policies`, `#materials`
- Week rail links: `.week-rail` (match section ids)

## How to use
Open `index.html`. Share with cohort. Print via browser — `print.css` linked.

## Customisation notes
Text-first — no video hero or instructor carousel. Week structure is the spine.

## Accessibility / print / mobile notes
Skip link, 17px body, week rail on desktop. Meta table stacks on mobile. Print hides rail. No JS required.
